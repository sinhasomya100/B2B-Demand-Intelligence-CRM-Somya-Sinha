## What I Built
An AI-powered Demand Intelligence pipeline that automatically generates 
personalised B2B outreach messages using Make.com + OpenAI + Notion.

## How It Works
Notion CRM → Make.com automation → OpenAI generates outreach → Saves back to Notion

## Tech Stack
- Notion (CRM + Pipeline Board)
- Make.com (Automation)
- OpenAI GPT (AI outreach generation)

## 10 Real Companies Tracked
Funding signals, SDR hiring, market expansion — scored by ICP fit and readiness.
